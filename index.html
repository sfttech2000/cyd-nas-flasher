CYD-NAS · microSD network storage

ติดตั้ง CYD-NAS ผ่านเบราว์เซอร์

เปลี่ยนบอร์ด CYD (ESP32-2432S028R จอเหลือง 2.8") กับการ์ด microSD ให้เป็นที่เก็บไฟล์ในบ้าน อัปโหลด/ดาวน์โหลดผ่านหน้าเว็บได้ทุกเครื่องในวง WiFi เดียวกัน ติดตั้งครั้งแรกหรืออัปเดตจากคอมพิวเตอร์ (Chrome หรือ Edge) หรือมือถือ Android (Chrome กับสาย OTG) ไม่ต้องลงโปรแกรม

เวอร์ชัน …ฟรีใช้ในวง LANชื่อไฟล์ภาษาไทยตั้ง WiFi บนจอทัชฟอร์แมตการ์ดบนเครื่อง
เบราว์เซอร์นี้ใช้ไม่ได้
เปิดหน้านี้ด้วย Google Chrome หรือ Microsoft Edge บนคอม หรือ Chrome บนมือถือ Android · iPhone และ iPad ติดตั้งไม่ได้ (Apple ไม่เปิดให้เว็บใช้พอร์ต USB) แต่ใช้งาน NAS ผ่านเว็บได้ตามปกติหลังติดตั้งแล้ว

สิ่งที่ต้องมี

  • บอร์ด ESP32-2432S028R รุ่นพอร์ต micro-USB (จอ ILI9341) · รุ่น USB-C 2 พอร์ตบางล็อตใช้จอ ST7789 อาจสีเพี้ยนหรือไม่ติด
  • การ์ด microSD (ทดสอบกับ SanDisk Ultra 64GB) · ไม่ต้องฟอร์แมตมาก่อน เครื่องฟอร์แมตเป็น FAT32 ให้ได้
  • WiFi 2.4 GHz และอแดปเตอร์ 5V 2A สำหรับเสียบใช้งานจริง

1. เสียบบอร์ด

  1. คอม: เสียบด้วยสาย USB ที่ส่งข้อมูลได้ และปิดโปรแกรมอื่นที่อาจใช้พอร์ต เช่น Arduino IDE, PlatformIO, Serial Monitor
  2. มือถือ: ใช้สาย USB-C ↔ micro-USB หรือหัวแปลง OTG จอบอร์ดควรติด (OPPO, realme, vivo บางรุ่นต้องเปิด “การเชื่อมต่อ OTG” ในตั้งค่าก่อน)

2. เลือกแบบติดตั้ง

ไฟล์ในการ์ด microSD ไม่ถูกแตะ ไม่ว่าเลือกแบบไหน (ลบไฟล์ในการ์ดได้เฉพาะเมนูฟอร์แมตบนเครื่อง)

3. ติดตั้ง

กดปุ่มแล้วเลือกบอร์ด (ชื่อมักเป็น “USB Serial”, “CH340” หรือ COM) แล้วกดเชื่อมต่อ

ใช้เวลาประมาณ 1–2 นาที อย่าถอดสายหรือปิดจอมือถือระหว่างนี้ · ค้างที่ “กำลังเชื่อมต่อ” นาน: กดปุ่ม BOOT ที่บอร์ดค้างไว้แล้วลองใหม่
ตั้งค่าขั้นสูง / บันทึกการทำงาน

ความเร็ว 


    

  


  

    
หลังติดตั้ง

    
    
      
  1. เปิดครั้งแรก: แตะกากบาทแดง 3 จุดเพื่อปรับทัช (ทำครั้งเดียว)
    2. 
      
  2. จอสแกน WiFi ให้ แตะเลือกเครือข่าย แล้วพิมพ์รหัสด้วยคีย์บอร์ดบนจอ (มีตัวพิมพ์ใหญ่/เล็ก ตัวเลข และเครื่องหมายครบ)
    3. 
      
  3. เสียบการ์ด microSD · ถ้าการ์ดยังไม่ใช่ FAT32 จอจะถามให้ฟอร์แมต: กดปุ่มแดงค้าง 3 วินาที
    4. 
      
  4. เปิดเว็บ http://cyd-nas.local (หรือ IP ที่จอบอก) แล้วใส่ Login ที่แสดงบนจอ · เปลี่ยนรหัสได้ที่ปุ่ม ⚙ บนหน้าเว็บ
    5. 
      
  5. ปุ่ม Settings บนจอ: เปลี่ยน WiFi, ข้อมูลการ์ด/ฟอร์แมต, ปรับทัชใหม่, รีสตาร์ท
    6. 
    

    
ใช้ในวง LAN เท่านั้น อย่าเปิด port ออกอินเทอร์เน็ต (HTTP ไม่เข้ารหัส)

  


  

    
ทำอะไรได้บ้าง

    
    
      
  • หน้าเว็บจัดการไฟล์: อัปโหลด (ลากไฟล์หรือทั้งโฟลเดอร์มาวาง) ดาวน์โหลด เปลี่ยนชื่อ/ย้าย ลบ สร้างโฟลเดอร์ · มี progress bar
    • 
      
  • ชื่อไฟล์และชื่อ WiFi ภาษาไทยแสดงได้ทั้งบนเว็บและบนจอ
    • 
      
  • จอแสดง WiFi, IP, Login, พื้นที่การ์ด และกิจกรรมล่าสุด · ถอดการ์ดระหว่างใช้ได้ เครื่องไม่ค้าง เสียบกลับแล้วใช้ต่อ
    • 
      
  • ความเร็วราว 0.5–0.6 MB/s ผ่าน WiFi (ไฟล์ 10MB ราว 16 วินาที) · ไฟล์ละไม่เกิน 4GB (ข้อจำกัด FAT32)
