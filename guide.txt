CYD-NAS คู่มือการใช้งาน
=======================

CYD-NAS เปลี่ยนบอร์ด CYD (ESP32-2432S028R) กับการ์ด microSD เป็นที่เก็บไฟล์ในบ้าน
เปิดหน้าเว็บจากคอมหรือมือถือที่อยู่ในวง WiFi เดียวกัน แล้วอัปโหลด ดาวน์โหลด จัดการไฟล์ได้


1. เปิดเครื่องครั้งแรก
----------------------
- ปรับทัช: แตะกากบาทแดงให้ตรง 3 จุด (มุมซ้ายบน ขวาบน ซ้ายล่าง) ทำครั้งเดียว
- ตั้ง WiFi: จอสแกนให้ แตะชื่อ WiFi (หน้าละ 5 รายการ กด < > เปลี่ยนหน้า, Rescan สแกนใหม่)
  แล้วพิมพ์รหัสด้วยคีย์บอร์ดบนจอ
    ABC / abc   สลับตัวพิมพ์ใหญ่-เล็ก
    ?123        ตัวเลขและเครื่องหมาย  ->  #+= เครื่องหมายชุดที่ 2
    Show        ดูรหัสที่พิมพ์   Del ลบ   Connect เชื่อมต่อ
  ต่อไม่ได้: เลือก "Edit password" แก้รหัส หรือ "Network list" เลือก WiFi อื่น
- ใช้ได้เฉพาะ WiFi 2.4 GHz


2. หน้าจอสถานะ
---------------
  WiFi    ชื่อ WiFi และความแรงสัญญาณ
  IP      ที่อยู่ของเครื่องในวง LAN
  URL     http://cyd-nas.local
  Login   ชื่อผู้ใช้ / รหัสผ่าน สำหรับเข้าเว็บ (สุ่มให้ตอนเปิดครั้งแรก)
  SD      พื้นที่ใช้ไป / ทั้งหมด
  Sys     เวลาเปิดเครื่อง และหน่วยความจำ
  ด้านล่าง กิจกรรมล่าสุด (UP อัปโหลด, DL ดาวน์โหลด, DEL ลบ, REN เปลี่ยนชื่อ)

ปุ่ม Settings (มุมขวาบน)
  WiFi          เปลี่ยนเครือข่าย
  SD / Format   ดูข้อมูลการ์ด และฟอร์แมต
  Touch         ปรับทัชใหม่
  Restart       รีสตาร์ทเครื่อง


3. การ์ด microSD
----------------
- ใช้การ์ด FAT32 · การ์ดใหม่ (มักเป็น exFAT) หรือการ์ดที่มีหลายพาร์ทิชัน
  เสียบแล้วจอจะถามให้ฟอร์แมต
- ฟอร์แมต: Settings > SD / Format > กดปุ่มแดง "Hold 3s to FORMAT" ค้างจนแถบเต็ม
  (ปล่อยก่อน = ยกเลิก) ใช้เวลาราว 10 วินาที  ** ข้อมูลในการ์ดหายทั้งหมด **
- ถอดการ์ดตอนเครื่องเปิดอยู่ได้ (อย่าถอดระหว่างอัปโหลด) จอขึ้น SD ERROR เสียบกลับแล้วใช้ต่อได้
- ไฟล์ละไม่เกิน 4GB (ข้อจำกัดของ FAT32)


4. หน้าเว็บ
-----------
เปิด http://cyd-nas.local (ถ้าไม่ขึ้น ใช้ IP ที่จอบอก เช่น http://192.168.1.50)
ใส่ Login ตามที่จอบอก

- อัปโหลด: ปุ่ม "อัปโหลด" หรือลากไฟล์มาวางบนหน้าเว็บ
- อัปโหลดทั้งโฟลเดอร์: ปุ่ม "อัปโหลดโฟลเดอร์" หรือลากโฟลเดอร์มาวาง
- ดาวน์โหลด: ปุ่ม ⬇ · แตะชื่อไฟล์ = เปิดดูในเบราว์เซอร์ (รูป, PDF, วิดีโอ, ข้อความ)
- เปลี่ยนชื่อ ✏ (ใส่ /โฟลเดอร์/ชื่อ เพื่อย้าย) · ลบ 🗑 (โฟลเดอร์ต้องว่างก่อน)
- ⚙ เปลี่ยนชื่อผู้ใช้และรหัสผ่าน
- ความเร็วราว 0.5-0.6 MB/s · อัปโหลดทีละไฟล์ตามคิว


5. ข้อควรรู้
-----------
- ใช้ในวง LAN เท่านั้น อย่าเปิด port ออกอินเทอร์เน็ต (HTTP ไม่เข้ารหัส)
- ลืมรหัสเข้าเว็บ: ดูบนจอ บรรทัด Login
- ย้ายไปใช้ WiFi อื่น: Settings > WiFi · ถ้า WiFi เดิมหลุด เครื่องจะต่อใหม่เอง
- ทัชเพี้ยน: Settings > Touch หรือแตะจอค้างไว้ตอนเสียบไฟ
- อัปเดตเฟิร์มแวร์: เปิดหน้าติดตั้งแล้วเลือก "อัปเดต" ค่า WiFi รหัส และไฟล์ในการ์ดยังอยู่
